## 🎮 ゲームのルールと仕組み

### 1. ビュフォンの針の近似式
平行線（間隔 $d$）に対して長さ $L$ の針を投げたときの交差確率から、円周率 $\pi$ は以下の式で推定できます。

$$\pi \approx \frac{2 \times L \times \text{総投数 } N}{d \times \text{交差数 } H}$$

### 2. 角度による「交差HIT」と「意図的MISS」の駆け引き
* **深い角度（ラインに対して垂直に近い）で命中 → 交差HIT**
  * 交差数 $H$ が増え、スコアが加算されます。
  * ラインに針が突き刺さり（最大10本まで保持）、コンボや壁反射（`BANK HIT`）で高得点が狙えます。
* **浅い角度（ラインに対して平行に近い）で命中 → MISS計測**
  * 交差数 $H$ は増えず、総投数 $N$ のみがカウントされます。
  * **連続で当てすぎると推定πが `3.14` より小さく（メーター左へ）ズレてスコア倍率が下がる**ため、あえて浅い角度で外して推定πを `3.14` 付近へ戻すテクニカルな調整が重要になります。

### 3. πバランスメーターとスコア倍率
画面中央のメーターで現在の推定πのズレがリアルタイムに表示されます。

| 推定πと `3.14159` の誤差 | スコア倍率 | 状態 |
| :--- | :---: | :--- |
| **±0.05 以内** | **×3.0** | FEVER（最大倍率・ライン緑発光） |
| **±0.15 以内** | **×2.0** | HIGH（高倍率・ライン緑発光） |
| **上記以外（当てすぎ / 外しすぎ）** | **×0.5 〜 ×0.8** | 倍率ダウン（角度調整でリカバリー） |

## 🕹️ 2つのゲームモード

1. **⏱ 30秒スコアアタック**
   * 制限時間30秒間でどれだけ高いスコアを稼げるかを競うモードです。
   * 推定πを `3.14` 付近にキープして倍率 `×2.0〜×3.0` を維持しつつ、左右の壁にバウンドさせて当てる `BANK HIT` ボーナスを狙うのが高得点のカギです。
2. **🎯 π (3.14159) 最速近似**
   * 5投以上の状態で、推定πを **`3.1416`（誤差 ±0.04 以内）** に到達させるまでのクリアタイムを競うモードです。

## 📱💻 操作方法

### スマートフォン（タッチ操作）
* **SHOOTレバー（下部スライダー）**:
  * 指で押さえて左右にスライドすると砲台が連動して移動します。
  * **連射 Lv.0（単発）**: 指を離した瞬間に1発発射します。
  * **連射 Lv.1〜10**: 指を押さえている間、設定したレベルに応じた間隔で自動連射します。
* **連射レベル調整**: レバー上の `◀` / `▶` ボタンで `Lv.0` 〜 `Lv.10` を切り替えられます。

### PC（キーボード / マウス操作）
* **砲台の左右移動**: `←` `→` キー または `A` `D` キー（画面下部のSHOOTレバーのマウスドラッグでも移動可能）
* **発射 / 連射**: `SPACE` キー（押して離すと単発、連射Lv.1以上なら長押しで連射）
* **連射レベル調整**: `↑` `↓` キー または `W` `S` キー（画面上の `◀` / `▶` ボタンでも変更可能）
